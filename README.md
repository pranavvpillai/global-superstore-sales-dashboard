# Global Superstore Sales & Profitability Dashboard

## Overview
An interactive Tableau dashboard analyzing sales, profit, and customer behavior across the Global Superstore dataset — built to uncover which regions, categories, and discount strategies actually drive profitability.

## Tools Used
Tableau · Data Cleaning · Dashboard Design

## Dataset
Global Superstore dataset — 25,035 orders across multiple regions and product categories.

## Key Findings
- Built a dashboard suite of 2 dashboards, 5 KPI cards, and 11 visualizations analyzing $12.64M in sales and $1.47M in profit.
- Technology emerged as the top-performing category by sales, with the Central region generating the highest revenue.
- Overall profit margin came out to 11.61%, with an average order value of $504.99.
- Discount analysis showed profit margins turning negative once discounts exceeded roughly 40–50%, with Furniture showing the steepest losses at high discount levels.
- Based on this, recommended capping discounts below the ~40% threshold and prioritizing Technology and Central-region inventory investment.
